# Autoimmune Medicine Analysis 🧬📊

A Python script that visualizes the success rates of various autoimmune disease treatments using a clean, professional Matplotlib dashboard.

## Features
Generated a comprehensive 6-panel visualization including:
- **Bar Charts:** Individual and average success rates grouped by medicine category.
- **Line Graph:** Sorted success rate trends.
- **Pie Chart:** Distribution of medicines across classifications (Biologics, JAK Inhibitors, DMARDs, etc.).
- **Box & Scatter Plots:** Variance and detailed distribution analysis.
